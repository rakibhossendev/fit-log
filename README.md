## Project Name: FitLog

## Description

This is a fitlog web site. There you can track your fit progress. You can add your exercise and show how many duration,calories. And if you went you can save your plans i save section. You can view details of your exercise. 

### Technologies 
- Next.js
- TypeScript
- Tailwind Css
- Daisy UI

### Features
- You can add your plans in plan section.
- You can show your progress after done.
- If you went. You can save your plan in save section.
- There is Responsive and Modern User Interface.
- View details any plans.
